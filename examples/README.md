# Examples

End-to-end usage examples for prime-rl, referenced from the top-level [README](../README.md).

- **[`basic/`](basic)**: worked baseline, SFT, RL, and evaluation flows for `reverse-text`, `alphabet-sort`, `wiki-search`, `wordle`, and `hendrycks-sanity`.
- **[`advanced/`](advanced)**: larger SLURM configs for Qwen3, GLM, MiniMax, Nemotron, and INTELLECT models, including P/D-disaggregated inference.

Dev-sized (2-GPU) counterparts of `basic/` live in [`configs/basic/`](../configs/basic).
